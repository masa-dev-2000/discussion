# 作業ログ

「先人会議」アプリの構築記録。新しい順ではなく、進行順に記載。
(コミット SHA は履歴整理のため変わる場合があります)

## 経緯

| 区分 | 内容 |
|---|---|
| 初版 | React + Vite + TypeScript で論壇 UI(モックデータ)を作成。会議場テーマの配色・吹き出し・人物レール。 |
| 画面構成 | **議論一覧 / 議論設定 / 論壇** の3ページに再編。依存なしのハッシュルーターを導入。 |
| 要約UI | 「流れのまとめ」を論壇のパネルから一覧の「要約」ボタン+モーダルに移動。論壇はチャット全幅に。 |
| A: 中核 | プロバイダ層(OpenAI 互換 SSE / デモ)とオーケストレーター(開会→各ラウンド→閉会)を実装。 |
| B: 自動要約 | 議論終了後に LLM で要約(本文+論点)を生成し一覧に反映。 |
| C: デスクトップ化 | Tauri で包む。`tauri-plugin-http` で API の CORS を回避。アプリアイコン生成。 |
| 永続化 | 議論一覧を localStorage に保存・復元。削除を追加。 |
| 拡張 | 人物ごとのモデル割当、議論の追記(続きのラウンド)、Tauri Store でのファイル保存。 |
| 接続性 | 接続テスト(`/models` 取得)を追加。接続先を **Ollama** に集約。インストール済みモデルを自動取得して選択。 |
| 実行基盤 | **バックグラウンド実行マネージャ**(多重実行・同時数上限・接続不可時のガード・画面離脱でも継続)。 |
| 介入 | **オブザーバ**(ユーザー)が議論に口を挟める。割り込み直後の登壇者が必ず応答するよう修正。 |
| アイデアエーション | 進め方モード(発散/批判/収束/討論)と発想ロールを追加。要約もモード対応(「出たアイデア」抽出)。 |
| UX | チャットの自動スクロールを廃止し「最新へ」ボタンに。 |
| 配布 | デスクトップ起動用ショートカット作成スクリプト(Windows)。 |
| 対話者拡充 | 「現代の実践者」(実業家・思想家・研究者・エンジニア)を追加。 |

## 開発メモ

- 検証は Vite preview + Playwright(ヘッドレス Chromium)でスクリーンショットを撮って確認。
- LLM 無しでも全機能を試せるよう「デモ」プロバイダを常設。
- Windows/PowerShell 前提のコマンドは `;` 区切り or 1行ずつ(`&&` 非対応)。
