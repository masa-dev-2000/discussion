# 0005. アイデアエーション向けの進め方モードと人物体系

- Status: Accepted
- Date: 2026-06

## Context

ツールの主目的は**アイデアエーション(発想)**。しかし当初の論壇は「反論し合う討論」に固定されており、
ブレストや収束といった発想プロセスに向いていなかった。

## Decision

- 議論に **進め方モード(`DiscussionMode`)** を持たせる: `diverge`(発散)/ `critique`(批判)/ `converge`(収束)/ `debate`(討論)。
  - オーケストレーターが各登壇者の発言ルール・司会の開会/閉会・要約プロンプトをモードで切り替える。
  - 発散/収束では要約で「出たアイデア」を抽出(最大8件)。
- 対話者を **3グループ**に整理: 発想ロール(オプティミスト等)/ 現代の実践者(実業家・思想家・研究者・エンジニア)/ 思想家(古典)。
- **オブザーバ**(ユーザー)が議論に割り込める。割り込みは次の登壇者の前に挿入し、その登壇者にまず応答させる。
- 人物ごとに使用モデルを上書き可能(例: 司会だけ賢いモデル)。

## Consequences

- 「発散→批判→収束」をメンバーとモードを変えて回せる、発想ツールとしての軸が通る。
- 現代の実在人物は**公開された発言・姿勢に基づく作風の再現**であり、その旨を UI に明記。
- モードやロールの追加が容易(`data/modes.ts` / `data/personas.ts`)。
- 旧データは `mode` を `debate` として移行。
